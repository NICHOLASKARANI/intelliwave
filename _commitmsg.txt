feat(hr): leave balance engine + auto-deduct on approve

Server side:

- New GET /api/wavecore/hr/leave-balances?employeeId=&year=
  Returns balances, seeding missing rows from LeaveType.daysPerYear.
- leaves POST now checks the employee's remaining balance before
  inserting. If insufficient, returns 409 with a clear message
  (requested / remaining / leave type).
- leaves/[id] PATCH now runs inside a transaction and adjusts
  LeaveBalance on any status change:
    PENDING -> APPROVED        usedDays += days
    APPROVED -> REJECTED       usedDays -= days (refund)
    APPROVED -> CANCELLED      usedDays -= days (refund)
    APPROVED -> PENDING        usedDays -= days (refund)
    APPROVED -> APPROVED (edit days) adjusts by the delta
  Uses GREATEST(0, ...) so usedDays / remainingDays never go below 0.
- leaves/[id] DELETE refunds balance first if the record was APPROVED,
  then deletes — inside the same transaction.
- Also cleans up an accidentally-committed _commitmsg.txt from the
  previous commit.

No schema change. next build clean.
